Ready-to-use Windows x64 package with a compiled OpenFX plugin, Depth Anything V2 Small model, ONNX Runtime and DirectML.

Download **AI-Depth-Pro-*-windows-x64.zip**, extract the whole archive, close Resolve and double-click **install.bat**. Approve the administrator prompt, then restart Resolve. No compiler or separate model download is needed. The `.sha256` asset provides the ZIP checksum.

Requires the Microsoft Visual C++ 2015-2022 x64 runtime: https://aka.ms/vs/17/release/vc_redist.x64.exe

Automated regression, persistent cache, mock OpenFX host and real ONNX inference tests run before publishing. Real DaVinci Resolve host testing is still pending, so this release is marked as a preview.
